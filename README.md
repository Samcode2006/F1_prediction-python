# 🏎️ F1 Race Winner Prediction System

A Python + React F1 race prediction system. Uses FastF1 data, enhanced rule-based scoring, and a modern React dashboard.

---

## 📁 Project Structure

```
F1_predicotor/
├── predictor.py         ← Core scoring & data-reading logic
├── fetch_data.py        ← Fetches current season data → drivers.csv
├── bulk_fetch.py        ← Pre-caches all past races (run once per season)
├── main.py              ← CLI interface
├── drivers.csv          ← Current race input (generated by fetch_data.py)
├── requirements.txt     ← Python dependencies
│
├── backend/
│   ├── api.py           ← FastAPI REST server
│   └── run.py           ← Uvicorn launcher
│
├── frontend/            ← React + Vite SPA
│   ├── src/
│   │   ├── pages/       ← Dashboard, Predict, RaceHistory, RaceDetail, DriverCompare
│   │   ├── components/  ← Navbar, PodiumCard, WeatherPanel, TelemetryChart
│   │   ├── api.js       ← API client helpers
│   │   └── index.css    ← Global design system (tokens, cards, tables, etc.)
│   └── package.json
│
├── tests/
│   └── test_predictor.py ← Property-based tests (Hypothesis + pytest)
└── cache/               ← FastF1 session cache (auto-populated)
```

## 🚀 Setup & Running

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
# or if using the bundled .venv:
.venv\Scripts\pip install -r requirements.txt
```

### 2. Pre-populate the cache (run once)

Downloads all past race sessions (Qualifying + Race) for 2024–2026:

```bash
python bulk_fetch.py
# Or for a specific year:
python bulk_fetch.py --years 2026
```

Errors are logged to `bulk_fetch_errors.log`.

### 3. Fetch latest race data

```bash
python fetch_data.py
```

This generates `drivers.csv` from the most recently completed race.

### 4. Start the backend API

```bash
python backend/run.py
```

API runs at `http://localhost:8000`. Interactive docs at `http://localhost:8000/docs`.

### 5. Start the React frontend

```bash
cd frontend
npm install     # first time only
npm run dev
```

App runs at `http://localhost:5173`.

### 6. (Optional) Run the CLI version

```bash
python main.py
```

## 📊 Scoring System (9 Factors)

| Factor | Logic | Max pts |
|--------|-------|---------|
| Qualifying Position | P1=10, P2=9, ..., P10=1 | 10 |
| Previous Race Finish | P1=10, P2=9, ..., P10=1 | 10 |
| Podium Form Bonus | +5 if P1–P3 last race | 5 |
| Team Strength | Constructor rating 1–10 | 10 |
| Grid Penalty | −2 per grid place penalty | 0 |
| Tyre Compound | +2 SOFT, 0 MEDIUM, −1 HARD | 2 |
| Wet Weather | Extra bonus for strong teams in rain | 3 |
| Championship Bonus | +1–3 for top-5 championship contenders | 3 |

## 🌐 API Endpoints

| Endpoint | Description |
|----------|-------------|
| `GET /api/predict` | Full ranked predictions (next race) |
| `GET /api/races` | All cached races |
| `GET /api/race/{year}/{round}/weather` | Weather summary for a race |
| `GET /api/race/{year}/{round}/telemetry` | Lap times & tyre data per driver |
| `GET /api/race/{year}/{round}/results` | Driver info for a race |
| `GET /api/constructors` | Constructor standings |
| `GET /api/health` | Health check |
